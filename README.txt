Облачный леденец 3D
Запуск: открой index.html в браузере (Chrome/Firefox/Safari).
Нужен интернет: three.js (r128) подгружается с cdnjs.cloudflare.com.
Управление: зажать мышь/палец и вести, либо WASD / стрелки. Рывок — Shift/Пробел или кнопка ⚡.

Три мира, у каждого своя атмосфера (небо, туман, свет, облака, острова, погода, цвета интерфейса):
  1. Сахарный закат   — розовое небо, пушистые облака, звёздочки.
  2. Мятная аврора    — ледяная ночь, северное сияние, луна, снегопад, гранёные ледяные облака.
  3. Грозовая карамель — огненный горизонт, гроза с молниями, дождь, тяжёлые грозовые облака.
В каждом новом мире прокачка и конфеты сбрасываются в ноль.
Кнопка «☰ Миры» — выбрать любой мир (в index.html константа FREE_SELECT=false оставит только открытые).
Адрес вида index.html?lvl=3 открывает нужный мир сразу.
Прогресс сохраняется в localStorage браузера.
